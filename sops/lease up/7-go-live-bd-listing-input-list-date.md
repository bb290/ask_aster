Go Live means two things: post the listing live in Buildium, and set the **💁 List Date** custom field on the LU task. That is the whole step.

## Post the Listing in Buildium

Buildium → Leasing → Listings → **Unlisted** tab → search the property address.

1. Edit Listing Details:
   - **Rent** — per the agreed listing strategy
   - **Deposit** — $100 less than asking rent
   - **Availability Date** — today's date, or the expected move-in date if pre-leasing
   - **Contact** — assigned Leasing Agent
2. Click **Post Listing**.

## Input 💁 List Date

1. Open the **LU | [Property Address]** parent task in Asana.
2. Set the **💁 List Date** custom field to today's date.

💁 List Date drives the days-on-market KPI. If it is left blank or backdated, the listing's performance reporting stays wrong for the life of the lease-up.
